# Espace Manager — Démo « Lumen & Co »

Version de démonstration publique de l'Espace Manager (originellement créé pour Soft Love by Nadine).

## Important
- **Marque 100% fictive** : « Lumen & Co » — vente en démonstration d'articles pour la maison (modèle type Tupperware généralisé)
- Toutes les personnes citées sont fictives, sauf **Laeticia** (manager, conservée en hommage)
- Aucune donnée réelle : montants, conditions et FAQ inventés
- L'original privé (données réelles) vit dans le dépôt privé `laetisoftlove`

## Accès démo
- Mot de passe `demo` → rôle démonstrateur
- Mot de passe `manager` → rôle manager (fonctions d'administration visibles)

Les mots de passe sont volontairement publics : c'est une vitrine technique.

## Ce que la démo montre (valeur showcase)
- Écran d'authentification à 2 niveaux (SHA-256, sessionStorage)
- Manuel d'équipe complet structuré (histoire, objectifs, formations, SAV, clôtures)
- FAQ dynamique : ajout/modification/suppression par la manager, sauvegarde automatique navigateur
- Modèles de mails du cycle de démo
- PWA installable (manifest, service worker, icônes)
- Charte de marque edukisto (logo, signature, favicon)
